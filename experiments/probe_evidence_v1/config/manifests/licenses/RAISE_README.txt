This is a set of 1000 real images derived from the RAISE dataset for non-commercial purposes.
The original RAISE dataset is available at the link: http://mmlab.science.unitn.it/RAISE/
Any published work using these data must include a reference to the RAISE paper [1].
This set is provided under the license of the original dataset, as detailed in the file: RAISE_License.pdf

[A] Duc-Tien Dang-Nguyen, Cecilia Pasquini, Valentina Conotter, and Giulia Boato.
    "RAISE: A Raw Images Dataset for Digital Image Forensics." In ACM MMSys, page 219–224, 2015.
