已保存模型00373覆盖5968/6184训练样本（约96.5%）；日志共6000条，最后32条对应更新未保存。不为补齐整轮单独开卡。16条内部开发初检中，loss由0.477338降至0.231076，严格位置有效仍0/16；唯一原句定位后，整段作者修正匹配0→4/16。后者是改善线索，不是语义准确率。前后硬件不同、评估量小、正例偏重、合成标签可能有误，均限制结论。

## 阶段A：有限CPU诊断及接口准备

执行获准后，优先完成这一阶段，不用GPU、教师API或新增依赖。

1. 复用原16条前后测、完整参考与作者修正，逐例核对关键差异。每例只存问题原句、证据卡引用、判断及一句依据；避免复制整篇材料。标记可多选：纯数字定位错误、重复引用歧义、漏检、错误替换、无依据新增、合理替代写法、作者标签争议、不确定。
2. 助手审阅显式标为非人审gold；疑难例保留不确定，不强行纳入通过。先记录语义判断，再对照作者匹配指标。16条已被查看，结果只用于开发诊断。
3. 拟将模型目标简化为：

   ```json
   {"问题":[{"回答原文":"有问题的原句","建议":"替换文本"}]}
   ```

   无问题时输出空数组；不把缺失的作者证据绑定或中文理由补造成标签。原始语言的引用和替换文本保留原样。
4. 复用diagnose_fava_quotes.py的唯一原句查找。程序计算位置；重复引用、重叠编辑或引用不存在时保留反馈，但拒绝自动修改。删除用空建议。纯插入训练目标由已有作者位置机械扩展为包含相邻原文的非空替换，并验证回放等于原作者修正；找不到唯一锚点时明确隔离，报告损失数量，不猜测。
5. 仅在新目录生成候选格式，保留原ID、来源组和原训练/开发归属；不重新随机划分、不覆盖旧目标。对6184条训练记录程序统计可转换/隔离数、操作类型及新监督token数；无论保留多少都报告真实覆盖，不缩成几十条训练。新格式不自动获得训练放行。
6. 最小检查覆盖唯一/重复引用、删除/插入、重叠编辑、空问题列表，以及所有可转换记录的回放一致性。采用内容和功能检查，禁止任何哈希校验。

交付：16条紧凑诊断表、接口说明、候选转换统计及CPU检查结果。若主要是内容错误，接口简化仍可保留，但不能当作已解决质量问题。

## 阶段B：扩大内部开发验证

### 样本和比较

拟选128条FAVA内部开发回答，含原16条诊断集和112条新增开发例。新增部分优先每来源组一条，兼顾长度、编辑类型及多问题回答；在生成前固定选择规则和ID，保存各层数量。与训练按原来源组隔离。原16条和新增112条分别报告，不把原16条当未见验证。

另拟加入最多32条无错误控制：优先使用已有可靠标注且未用于训练的材料；若缺乏可用材料，可在开发来源内审阅作者修正后的文本作为候选。作者修正和“未标错误”均不自动等于无错。确认为有证据支持后才纳入，不足32条就如实报告，不凑数。同源的错误/修正版本按配对控制处理，不计为独立来源；这只能测构造控制误改，不能外推自然无错分布。

比较旧00952与当前00373，使用相同样本、原提示、解码参数和同一GPU；每个模型最多160次生成，共320次。保留原始严格评分，同时对两组应用相同的引用定位后处理。这样先估计训练后的内容变化，避免同时改变训练与提示。

另拟用既有旧反馈开发材料中32条作能力回归检查，两个模型各生成一次，共64次。按既有暴露记录选取，覆盖中文反馈、证据引用和应保留内容；这些是回归集，不是独立测试。若现有材料不足以覆盖某能力，报告缺口。具体路径/ID在执行前核对并冻结，不动FULL20或GT/44保留组。

本阶段不把简化提示加入额外比较臂；避免扩大推理和混淆解释。简化格式模型需要另行决定训练后才能比较。

### 指标与分析

- 主要内容判断：必要修改是否有参考证据支持；每条回答是否引入错误修改；对无错控制是否错误提出修改。助手审阅有争议时单列，不充当人审准确率。
- 可程序计算的辅助指标：JSON有效、引用可定位、编辑回放、作者编辑匹配、整段作者修正匹配；逐项提供分母，未定位和失败例不静默删除。
- 报告两模型在同一回答上的改善/恶化/不变数；以来源组考虑相关性，不把同源版本和每个编辑当成独立样本。
- 为节省token，程序覆盖所有样本；语义复核优先覆盖全部无错控制、两模型结论变化例及自动检查异常例，再审阅预先选定的少量一致例。记录实际审阅覆盖；选择性审阅的结果不冒充全128条语义成功率。
- 128是有界开发诊断规模，没有做功效论证，不用于“显著优于”或上线达标结论；独立验证应在最终接口及训练方案固定后另行规划。

### 预算与停止

建议本阶段另批累计最多2 GPU小时、最多384次生成、零训练更新。预算包括加载、前后模型切换和回归检查；不是完成时长承诺。到达时间/次数任一上限即停止并保存覆盖，未完成项保留缺失，不自动加时重试。原8小时训练及20分钟后测授权已结束，不能移作本阶段预算。

运行前检查GPU可用性，在获准范围内直接用空闲资源。不得开启或购买GPU、停止他人进程；结束确认自有任务退出并告知可以关卡。连续工作每60秒提供有意义更新。模型/数据加载或输出持续失败时先停止自己的任务并诊断，不循环消耗预算。

## 阶段C：依据结果选择训练方向

| 观察到的结果 | 决策 |
|---|---|
| 主要障碍是数字位置，内容判断有改善、未见明确严重误改或旧能力退化 | 准备简化格式的受控SFT方案；比较时旧/新模型统一使用同一应用后处理 |
| 漏错或错误替换较多 | 先利用已有作者标签程序补足对应错误类型与多问题覆盖；不单纯增加epoch |
| 无错材料被频繁修改 | 优先完善有依据的无错监督及误改评估；先不接Actor自动修改 |
| 中文理由、证据引用或保留内容能力退化 | 将恢复任务能力作为下一轮目标，核对可复用旧监督；不把缺失字段编造成新标签 |
| 作者标注争议足以影响结论 | 隔离争议并报告；先解决监督质量，暂不追加训练 |

任一确认的严重无依据修改或旧能力损伤都需要解释和修复后再考虑晋级；样本中未观察到事故也不证明安全。所有分支都先交付证据和具体训练草案，不自动触发训练。

若进入新训练，优先复用完整合格训练池，提前报告独立样本数、监督token及预估耗时；不使用微量示例替代正式训练。起始检查点、是否混合旧反馈监督、数据用途及GPU预算需根据阶段A/B结果确定，本方案不预先授权，也不将旧预算结转。不得把多种改动的联合效果解释为某一个因素的因果效果。
