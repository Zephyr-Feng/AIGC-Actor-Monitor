## 已解决的口径

`tool_return`审核实际返回，保留 supported_by_source / not_returned_by_source / unassessable；`tool_capability`审核Tool Card声明的能力，使用 supported_by_card / contradicted_by_card / unassessable。Card未说明不等于否定。准备阶段固定audit_target，模型输出必须相同，两个引用栏互斥。

返回引用只取声明之前的同源返回叶子；能力引用只取该工具的Card叶子。准备时同时核对原始已批准可见包、返回时点、完整返回副本、指针和原值。该实现复用既有 `resolve_reference` / `obj` / R7分组结果，没有扩大读取来源。旧single_source、SFT数据、原始输出和指标不改。

能力卡只能证明声明的能力，不能证明某次执行确实返回了内容；返回的工具名称不能证明能力边界。卡片top3定义不能补出实际缺失列表。一般高偏离限定语仍可能含糊，不借新增类别强行解决。中文解释是最低结构要求，解析通过不保证解释正确。
