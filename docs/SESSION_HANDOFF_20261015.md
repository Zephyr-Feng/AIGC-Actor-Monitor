- Actor-B使用冻结Qwen3-VL-8B-Instruct基座，提示与结构化协议驱动，每图最多4次工具调用。当前未采用Actor轨迹SFT adapter；PPT的两组LoRA实验属于本地Monitor开发，不要混为Actor训练。
