# Monitor证据绑定与关系核验：6个监督草稿

2026-10-11。用户明确回复“可以，你进行吧”，批准先准备六例讨论草稿。六例全部来自冻结的72条训练材料，保留原主张、完整输入事实、Actor上下文与最终标签，仅重写示范输出。**没有训练、模型调用或远端操作，也没有读取36条预留题或74组真实预留材料。**

这一步的产出是可检查的监督示范，尚不能说明模型会执行这些步骤或错误已经解决。

## 想教会的具体行为

在给定主张下，先把所需证据绑定到本次返回中的对应对象和字段，记录实际值或缺失，再核验主张要求的关系，最后给出理由与判断。

草稿分为以下部分，顺序也按此安排：

1. `claim`：原样保留当前主张，不能改成图像真假判断。
2. `return_scope`：本次工具来源、返回步次和输入位置。
3. `evidence_bindings`：对象、字段路径、已给出/字段缺失、实际值和已有E引用。涉及区域时，region_id与被核字段须来自同一条目。
4. `relation_checks`：明确核验条件，连接已绑定证据，分别记为“满足”“不满足”或“无法核验”。
5. `reason`、`return_reference_ids`、`judgement`：理由忠于前述证据和核验；最终标签仍为“支持”或“无法据此支持”。

“不满足”表示已有证据使当前关系不成立；“无法核验”表示关键依据不足。二者在现有最终标签中都对应“无法据此支持”，理由必须保留区别。

缺失绑定不写`actual_value`，不借用邻近字段的E编号。草稿用`absence_scope_pointer`和该对象实际键列表记录在哪里检查缺失；它们是输入定位信息，**不是新增的E/S证据引用，也不是现行解析器已经接受的新规范**。已引用的region_id只能证明对象身份，不能单独证明该对象的数值或字段缺失。空JSON Pointer表示original_return根对象。

完整机器可读草稿另存私有目录`experiments/faithbench_monitor_v0/private/evidence_binding_drafts_v1_20261011/drafts.json`，其中`input_payload`是从训练prompt解析出的完整原输入；原prompt的输出指令只保留其hash作为出处，没有把新目标直接配给旧三字段训练prompt。草稿不是可直接送入现有trainer的数据。

## 例1：完整证据支持全部百分位100

原主张：“所有受检区域的偏离百分位都是100。”

绑定到global_forensic_analyzer本次返回：

|对象/字段|实际值|已有叶子引用|
|---|---|---|
|/scope/num_regions_examined|3|E1306|
|/most_atypical_regions/0：region_id / deviation_percentile|R12 / 100|E1325 / E1328|
|/most_atypical_regions/1：region_id / deviation_percentile|R13 / 100|E1331 / E1329|
|/most_atypical_regions/2：region_id / deviation_percentile|R14 / 100|E1321 / E1314|

关系核验：本题返回三个不同受检区域，检查数也为3，覆盖全部受检项；三个对应百分位各为100。两个条件均满足。

目标理由：“检查数3，三个不同受检区域R12、R13、R14的偏离百分位均为100，支持该观察主张。”判断：**支持**。

这里的覆盖判断依赖本题fixture中条目属于该次受检集合且身份不同；一般输入还须核验这些前提，不能只看列表项数与检查数相等就断定覆盖。

## 例2：条目仍完整，但第三项数值缺失

主张、Actor上下文与例1完全相同。实际返回只删除`/most_atypical_regions/2/deviation_percentile`，已有其余叶子编号保持；不删R14条目，也不删检查数。

|对象/字段|实际值或缺失|已有叶子引用|
|---|---|---|
|/scope/num_regions_examined|3|E1306|
|R12：region_id / deviation_percentile|R12 / 100|E1325 / E1328|
|R13：region_id / deviation_percentile|R13 / 100|E1331 / E1329|
|R14：region_id|R14|E1321|
|R14：deviation_percentile|字段缺失|无，不借用E1321或其他区域数值|

缺失核验位置：`/most_atypical_regions/2`，实际键只有`region_id`、`patch_id`、`bbox`。R14身份仍然已知，未知的是其偏离百分位。

关系核验：条目覆盖条件满足；全部百分位等于100的条件无法核验。目标理由：“检查数3，R12与R13的偏离百分位为100，但R14的对应字段缺失，无法支持全部受检区域均为100。”判断：**无法据此支持**。

原返回仍有max100、median100、异常数3和异常比例1。这些保留字段无法唯一确定第三项为100；核查用的兼容完整值[100,100,100]与[100,100,96]都保留这些统计，但全体100主张一真一假。兼容值仅用于草稿正确性核查，不进入输入或应生成目标，也不是新工具观测。

## 例3：检查数已知，异常数缺失

原主张：“当前只审核观察主张：所有受检区域都达到本题规定的异常阈值。”

|对象/字段|实际值或缺失|已有叶子引用|
|---|---|---|
|/scope/num_regions_examined|7|E1016|
|/observations/atypical_threshold_percentile|95|E1000|
|/observations/num_atypical_regions|字段缺失|无|
|/observations/atypical_fraction|字段缺失|无|

缺失核验位置：`/observations`，实际键为`atypical_threshold_percentile`、`max_deviation_percentile`、`median_deviation_percentile`。

关系核验：需要确定达到阈值95的区域数是否等于检查数7，当前缺少异常数及比例，也没有覆盖全体的逐项值，无法核验。目标理由：“检查数7与阈值95已给出，异常区域数和比例缺失，无法确认所有受检区域都达到该阈值。”判断：**无法据此支持**。

这例明确保留“检查数7已知”，避免把部分字段缺失写成所有数量都没给出。比例是可能提供等价支持的字段，不是要求它与异常数必须同时存在。当前最大值、中位数及局部条目仍不足以唯一决定全体达阈值。

## 例4：最大值与中位数相等

原主张：“本次返回的最大偏离百分位严格高于中位偏离百分位。”

|对象/字段|实际值|已有叶子引用|
|---|---|---|
|/observations/max_deviation_percentile|99|E1604|
|/observations/median_deviation_percentile|99.0|E1622|

关系核验：99与99.0数值相等，严格大于关系不成立。目标理由：“实际最大偏离百分位99、中位偏离百分位99.0，二者相等，不支持严格高于的主张。”判断：**无法据此支持**。

这例属于证据与主张不符，不能写成“中位数未给出”或“无法比较”。

## 例5：核对原始score，不能改核signal

原主张：“当前只审核观察主张：实际返回的 score 字段按六位小数舍入为0.173842。”

绑定：local_texture_analyzer本次返回的`/score`，原始值`0.27384220000000004`，已有引用E1900。

关系核验：先对绑定的score按六位小数舍入，得到0.273842，与主张0.173842不等。目标理由：“实际score按六位小数舍入为0.273842，与主张0.173842不符，无法据此支持。”判断：**无法据此支持**。

原始值中的浮点尾数保留；按原材料核查采用Decimal与ROUND_HALF_EVEN，当前数值不处于舍入平局。signal与阈值属于其他属性，不能替代当前score数值相等关系，也不能把这项观察审核改为图像真假裁决。

## 例6：阈值是文本中的明确记载

原主张：“实际返回的 observation 字段明确写出固定判定阈值为0.25。”

绑定：local_texture_analyzer本次返回的`/observation`，原文“局部纹理原始合成分数为 0.120000，固定判定阈值为 0.25，信号为 real_like。”，已有引用E2203。

关系核验：该实际字段明确含“固定判定阈值为 0.25”，符合当前文本归因主张。目标理由：“实际observation字段明确写出固定判定阈值为0.25，支持该文本归因主张。”判断：**支持**。

这只是核验返回文本中的记载，不把文本内阈值额外伪造成新的独立数字字段，不引用score或能力卡来代替原文。
